# ContractFlow — Data Analysis Branch

ContractFlow is an oil and gas contract operations platform currently in development. The platform is being built collaboratively by the **Software Development, Cloud Computing, and Data Analysis teams** with the goal of delivering a Minimum Viable Product (MVP).

This branch represents the work of the **Data Analysis team** in supporting the development of ContractFlow.

At the current stage of the project, ContractFlow has not yet generated production or operational data for analysis. Therefore, the primary focus of the Data Analysis team is to work closely with the Software Development and Cloud Computing teams to ensure that the platform is designed with a strong foundation for future data collection, analysis, reporting, and decision-making.

## Project Overview

ContractFlow is being developed as an oil and gas contract operations platform covering the contract lifecycle from bid through commissioning.

The platform is intended to support the management and monitoring of key operational areas, including:

* Contract operations
* HSE incidents and inspections
* Site daily activities
* Compliance records
* Project milestones
* Payments
* Documents
* Notifications

As the MVP is developed, these activities will generate structured data that can later be used for operational analysis, performance monitoring, and business intelligence.

## Workspace Layout

The main ContractFlow workspace is structured as follows:

* `apps/web` — Next.js dashboard
* `apps/api` — NestJS REST API
* `packages/contracts` — Shared API and domain contracts
* `infra` — Local PostgreSQL, Redis, and S3-compatible object storage

The Data Analysis branch focuses on the analytical requirements and future data capabilities of the platform while remaining aligned with the overall MVP architecture.

## Local Setup

1. Copy `apps/api/.env.example` to `apps/api/.env`.

2. Start the infrastructure:

```bash
docker compose -f infra/docker-compose.yml up -d
```

3. Install dependencies:

```bash
npm install
```

4. Generate the Prisma client:

```bash
npm run prisma:generate --workspace=@contractflow/api
```

5. Apply local migrations:

```bash
npm run prisma:migrate --workspace=@contractflow/api
```

6. Run the web application:

```bash
npm run dev:web
```

7. Run the API:

```bash
npm run dev:api
```

The API is served at:

```text
http://localhost:3001/api/v1
```

Swagger documentation is available at:

```text
http://localhost:3001/api/docs
```

## Current Branch Objective

The current objective of the Data Analysis branch is to ensure that ContractFlow is being developed with **data readiness in mind**.

Rather than analysing historical platform data, the team is contributing to the development of the MVP by helping answer questions such as:

* What data should each module capture?
* Which fields are required for future analysis?
* What KPIs should ContractFlow be able to measure?
* How should related operational data be structured?
* What data quality standards should be established?
* What dashboards and reports will decision-makers require?
* How can the platform architecture support future analytics?

## Project Goal

The immediate goal is to contribute to the successful development of the ContractFlow MVP.

The long-term goal is to ensure that, as users begin to interact with the platform, ContractFlow generates reliable, structured, and analysis-ready data.

This will allow the platform to evolve beyond contract operations management into a system capable of supporting:

* Operational reporting
* Performance monitoring
* Business intelligence
* Risk identification
* Trend analysis
* Data-driven decision-making

The Data Analysis team's role is therefore not only to analyse data after it is generated, but also to help ensure that the MVP being built today produces the right data for the decisions that will need to be made tomorrow.
